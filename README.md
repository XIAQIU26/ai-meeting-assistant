# AI 科研组会管理助手 Web Demo

面向研究生和科研人员的 AI 组会管理工具 Demo。前端使用 React + TypeScript + Tailwind CSS，后端使用 Node.js + Express，Demo 默认使用轻量文件数据库保存记录，数据库服务层可替换为 SQLite / MongoDB。

## 运行

```bash
pnpm install
pnpm dev
```

- Frontend: http://localhost:5173
- Backend: http://localhost:4000/api

## 功能

- Dashboard 科研首页
- AI 组会记录解析与保存
- 组会历史、搜索、详情和任务状态
- 基于历史数据的 AI 科研助手
- 导师意见趋势分析
- 下一次组会准备助手
